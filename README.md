## Project Overview
This project develops a machine learning-based system that analyses hostel electricity consumption, identifies usage patterns, predicts energy requirements, and provides insights to reduce electricity wastage.

## ML Algorithms Implemented
1. **Linear Regression** - Predict daily energy consumption (kWh)
2. **Decision Tree Classifier** - Classify Normal vs High consumption
3. **K-Means Clustering** - Discover consumption patterns
4. **Principal Component Analysis (PCA)** - Dimensionality reduction and visualisation

## Dataset
Synthetic dataset (1,825 records) modelling 5 university hostels over 365 days. The dataset is generated with realistic relationships between occupancy, temperature, AC usage, and energy consumption based on Ahmedabad climate patterns.
